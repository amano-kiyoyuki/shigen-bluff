# 四元ブラフ

火・水・土・風の相性を読み、相手の裏をかく2人対戦カードゲームです。

## 遊ぶ

[四元ブラフを開く](https://amano-kiyoyuki.github.io/shigen-bluff/)

「CPUと遊ぶ」から、CPUとの2人対戦を遊べます。連勝記録はブラウザ内に保存されます。

オンライン対戦は、Firebaseの本番ルールとの整合を確認するため一時停止しています。

## ルール

各ラウンドで約5秒以内にカードを1枚選び、全5ラウンドの合計点で勝負します。手札は火・水・土・風が各2枚の計8枚で、5枚を使います。

通常点は全て10点です。火→水→土→風→火の順に強く、相性で勝つと勝者は15点（通常点の1.5倍）、相手は0点です。同じ記号なら両者0点、それ以外は両者10点です。

相性の図はゲーム画面に表示されます。矢印の先にある記号に勝ちます。

## データと運用

- アカウント登録は不要です。
- 連勝記録は利用中のブラウザ内に保存され、別の端末とは共有されません。
- この公開版ではFirebaseへのログインとデータベース接続を無効にしています。
