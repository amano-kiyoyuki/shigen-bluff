# 四元ブラフ

火・水・土・風のカードを同時に出し合い、同じカードが重なるとそのカードは0点になる読み合いゲームです。

## 遊ぶ

[四元ブラフを開く](https://amano-kiyoyuki.github.io/shigen-bluff/)

名前とプレイ人数（2〜4人）を選び、「ゲーム開始」を押してください。あなた1人とCPUで対戦します。各ラウンドでは約5秒以内にカードを1枚選び、全5ラウンドの合計点で勝負します。

| カード | 点数 |
|---|---:|
| 火 | 80点 |
| 水 | 50点 |
| 土 | 30点 |
| 風 | 10点 |

同じカードを出したプレイヤーは全員0点です。

## 連勝記録

現在の連勝数と最高記録は、このブラウザ内に保存されます。サーバーへの記録やアカウント登録はありません。同じブラウザで遊ぶと記録を引き継げますが、別のブラウザや端末とは共有されず、サイトデータを消すと記録も消えます。
