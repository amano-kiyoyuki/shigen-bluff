# 四元ブラフ

火・水・土・風の相性を読み合う、ブラウザーで遊べる2人対戦カードゲームです。

**公開ページ:** https://amano-kiyoyuki.github.io/shigen-bluff/

## 遊び方

- CPU対戦とオンライン対戦に対応しています。
- 2人で全5ラウンドを戦います。各記号2枚ずつ、計8枚の手札から5枚を使います。
- 火→水→土→風→火の順に強く、相性で勝つと15点。同じ記号は両者0点、それ以外は両者10点です。
- 各ラウンド約5秒以内にカードを1枚選びます。時間切れでは手札から自動で選びます。
- 連勝記録はブラウザー内に保存され、同じブラウザーで続けて遊ぶときに引き継がれます。

## オンライン対戦

オンライン対戦はFirebase Realtime Databaseと匿名認証を使います。アカウント登録は不要です。友達とは部屋コードで合流でき、ランダムマッチも利用できます。

1部屋につき1試合で、対戦は2人までです。再戦するときは、新しい部屋を作成してください。通信切断などでカードを照合できない場合は、勝者を決めず無効試合になります。

## 技術構成

- 静的ファイルをGitHub Pagesで配信
- Firebase Authentication（匿名認証）
- Firebase Realtime Database（同期とサーバールール）
- Cloud Functionsや常時稼働サーバーは使用しません

`firebase-config.js`にはWebアプリ用の公開クライアント設定を含みます。サービスアカウント鍵などの秘密情報は含めません。データベースへのアクセスはFirebase Realtime Databaseのセキュリティルールで制限します。

## 主なファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム画面とCPU対戦・オンライン対戦 |
| `spark-protocol.js` | カード確定、照合、手札と得点計算 |
| `spark-client.js` | Firebase接続と秘密値のブラウザー保存 |
| `firebase-config.js` | Firebase Webアプリの接続設定 |
| `database.rules.json` | Realtime Databaseのセキュリティルール |
| `tools/build-rules.cjs` | セキュリティルールの生成元 |
| `tests/` | ルールと画面の自動テスト |

## 開発者向け

ローカルで遊ぶ場合は、プロジェクト内のファイルサーバーから`index.html`を開いてください。オンライン機能を開発・検証するときはFirebase Emulatorを使えます。手順とテスト方法は開発用リポジトリを参照してください。
