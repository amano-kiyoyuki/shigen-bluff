# 四元ブラフ

火・水・土・風のカードを同時に出し合い、同じカードが重なるとそのカードは0点になる読み合いゲームです。

## 遊ぶ

[四元ブラフを開く](https://amano-kiyoyuki.github.io/shigen-bluff/)

「CPUと遊ぶ」では、名前とプレイ人数（2〜4人）を選び、CPUと遊べます。連勝記録はブラウザ内に保存されます。

「オンライン対戦」では、2〜4人で対戦できます。部屋を作って招待URLまたは4文字の部屋コードを共有するか、ランダムマッチを使ってください。オンライン対戦には通信環境が必要です。

## ルール

各ラウンドで約5秒以内にカードを1枚選び、全5ラウンドの合計点で勝負します。

| カード | 点数 |
|---|---:|
| 火 | 80点 |
| 水 | 50点 |
| 土 | 30点 |
| 風 | 10点 |

同じカードを出したプレイヤーは全員0点です。オンラインでは全員のカードを公開後に照合し、通信切断や記録の不一致を確認した場合は、勝者を決めず無効試合にします。

## データと運用

- アカウント登録は不要です。オンライン対戦ではFirebaseの匿名認証を使います。
- CPU戦の連勝記録は利用中のブラウザ内に保存され、別の端末とは共有されません。
- Firebaseの公開クライアント設定を使用します。データベースへのアクセスはRealtime Databaseのセキュリティルールで制限します。
- FirebaseはSpark（無料）プランで運用します。無料枠には上限があり、利用状況によりオンライン対戦が一時的に使えなくなる場合があります。
- 部屋や招待データは自動で全件削除されません。不要な部屋の確認と整理が必要です。

オンライン機能はカジュアル対戦向けです。中央ランキング、賞金付き対戦、悪意ある切断を完全に防ぐ仕組みはありません。
